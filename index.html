University Study Agent

University Study Agent is a personal study organizer for one university student. It checks newly received university email, identifies course tasks and readings, and adds reviewable items to the student's existing Notion workspace. Optional Moodle file sync is planned.

The app requests read-only Gmail access. It does not send email, submit coursework, or delete files. Uncertain items are marked for human review.

Access is limited to the account owner. This is a private project under development and is not offered as a public service.

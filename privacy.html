Privacy Policy

University Study Agent is a personal tool for its account owner. It is not available for public registration.

Data accessed

With the owner's consent, the app uses the Gmail API's gmail.readonly permission to read new university email messages, including sender, subject, body, message identifiers, and thread identifiers. It reads course names and task properties from the owner's existing Notion workspace. Future optional Moodle and cloud file connections will be used only after the owner authorizes them.

How data is used and shared

The app filters new email locally before AI analysis. For messages that appear related to study, it sends the sender, subject, and relevant body text, together with known course names, to the OpenAI API to identify tasks, readings, courses, and due dates. The app then writes the extracted task title, course, date when explicit, source link, and a short evidence excerpt to the owner's Notion workspace. Uncertain results are marked for review. Google user data is not sold, used for advertising, or shared for unrelated purposes.

Storage and retention

The private worker stores processed message identifiers, task links, run history, and estimated AI usage in its database to prevent duplicates and support an activity log. It does not store full email bodies in that database. Extracted task information and short evidence excerpts remain in Notion until the owner changes or removes them. The owner controls the worker's database and can remove its data or revoke Gmail access through Google Account settings. OAuth credentials are kept in restricted configuration, separate from this public site.

Security and controls

Data is transferred over HTTPS. The Gmail permission does not allow the app to send or delete email. The owner can stop the workflow in n8n and revoke the Google connection at any time. No autonomous submission of coursework is implemented.

Questions

The account owner can use the support email shown on the Google consent screen or the project's GitHub issue tracker. Do not post private email contents or credentials in a public issue.
